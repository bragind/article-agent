# 🤖 AI RAG-агент для поиска статей

**Интеллектуальный поиск и анализ IT-статей**

## 🌟 О проекте

AI RAG-агент для интеллектуального поиска и анализа статей технологических СМИ. Проект создан для Cloud.ru в рамках хакатона по разработке MVP AI-агента на основе RAG-архитектуры.

### 🎯 Цель проекта
Создание MVP AI-агента, способного:
- 🔍 Находить статьи по запросу с учетом семантического смысла
- 📝 Генерировать краткие аннотированные резюме
- 🔗 Указывать источники с авторством
- ❓ Предлагать вопросы для самопроверки
- 📊 Анализировать и визуализировать контент

## 🚀 Возможности

### 🔍 Умный поиск
- **Семантический поиск** по статьям Habr и пользовательским документам
- **Фильтрация** по тегам, автору, дате публикации
- **Векторное кодирование** с использованием Sentence Transformers
- **Гибкая область поиска** (везде, только Habr, только мои документы)

### 📚 Управление документами
- **Загрузка PDF-документов** в личную коллекцию
- **Автоматическая генерация тегов** через LLM
- **Изоляция документов** по пользователям
- **Статистика** загруженных документов

### 🧠 Интеллектуальный анализ
- **Вопросы для самопроверки** по каждой статье
- **Поиск похожих статей** на основе контента и метаданных
- **Генерация кратких резюме** через локальную LLM (Ollama)
- **Расширенная статистика** и аналитика контента

### 👥 Пользовательская система
- **Ролевая модель** (гость, пользователь, администратор)
- **Безопасная аутентификация** с bcrypt
- **Сессионное управление** с таймаутом
- **Индивидуальные коллекции** документов

### Технологический стек
- **Backend**: Python 3.10+
- **UI Framework**: Streamlit
- **Vector DB**: ChromaDB
- **Embeddings**: sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2
- **LLM**: Ollama с llama3.2:3b
- **Auth**: bcrypt + PyJWT
- **Parsing**: BeautifulSoup4, lxml
- **PDF Processing**: pdfplumber
- **Visualization**: Plotly, Pandas

## 📦 Установка и запуск

### Предварительные требования
- Python 3.10 или выше
- [Ollama](https://ollama.ai/) для локальной LLM
- 4+ GB RAM, 2+ GB свободного места на диске

### Шаг 1: Клонирование репозитория
```bash
git clone https://github.com/bragind/article-agent.git
cd article-agent
```

### Шаг 2: Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 3: Запуск Ollama
```bash
ollama serve
# В другом терминале
ollama pull llama3.2:3b
```

### Шаг 4: Инициализация системы
```bash
# Инициализация аутентификации
python scripts/init_auth.py

# Сбор статей (опционально)
python parser_articles/main.py

# Построение векторного индекса
python scripts/build_index.py --data data/articles_batch.jsonl
```

### Шаг 5: Запуск приложения
```bash
streamlit run src/streamlit_app.py
```

Приложение будет доступно по адресу: [http://localhost:8501](http://localhost:8501)

## 🎮 Использование

### 🔐 Первый вход
1. Используйте тестовые учетные данные:
   - **Администратор**: `admin` / `admin123`
   - **Пользователь**: `test` / `test123`
   - **Гость**: вход без регистрации (ограниченный функционал)

### 🔍 Поиск статей
1. Перейдите на вкладку **"Поиск"**
2. Введите запрос (например: "машинное обучение в медицине")
3. Используйте фильтры для уточнения результатов
4. Просмотрите найденные статьи с вопросами для самопроверки

### 📤 Загрузка документов
1. Перейдите на вкладку **"Мои документы"**
2. Загрузите PDF-файл (макс. 100MB)
3. Документ автоматически проиндексируется
4. Ищите по содержимому ваших документов

### 📊 Статистика
1. Перейдите на вкладку **"Статистика"**
2. Просмотрите аналитику по статьям
3. Изучите популярные теги и авторов
4. Отслеживайте динамику публикаций
